# AgriRain ML

Machine Learning-Based Analysis of Indian
Monsoon Variability and Agricultural Vulnerability.

## Project Overview

AgriRain ML investigates the relationship between
monsoon rainfall variability and agricultural
productivity across India using machine learning.

## Objectives

- Analyse historical rainfall patterns.
- Identify regional agricultural vulnerability.
- Apply unsupervised learning.
- Predict crop yield using regression models.
- Optimise and evaluate ML models.
